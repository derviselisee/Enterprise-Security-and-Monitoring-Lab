## ENTERPRISE SECURITY AND MONITORING LAB

Enterprise Security and Monitoring Lab with Active Directory, LDAP, Wazuh, Zabbix, GLPI, Kali Linux, FortiGate Security, High Availability, and Hybrid Cloud Integration.

---

## Project Overview

This project simulates how a real enterprise builds and operates a secure infrastructure. The lab integrates identity services, firewall security, monitoring, SIEM detection, and hybrid cloud connectivity. Because every system has a defined role, the environment supports realistic SOC operations, enterprise monitoring workflows, and threat detection validation.

This lab provides real world operational experience in enterprise security architecture, SOC monitoring workflows, and hybrid infrastructure protection.
